# Scheduling Agent

A Scheduling Agent project scaffold for an undergraduate artificial intelligence course. The planned product uses TanStack Start, React, shadcn/ui, FullCalendar, pi Agent SDK, and SQLite. The repository currently provides scaffolding, dependencies, and engineering constraints; business logic, database models, and the final UI have not been implemented.

## Current status

- Minimal React routing scaffold from TanStack Start
- Base configuration for Tailwind CSS 4 and shadcn/ui
- FullCalendar v7 React dependency and official shadcn registry configuration
- pi Agent SDK dependency
- Drizzle ORM, better-sqlite3, and migration tooling dependencies
- Vitest, Testing Library, and Playwright testing dependencies
- ESLint, Prettier, TypeScript, and a minimal agent harness

The home page is still the placeholder generated by the TanStack CLI. The repository has no calendar, agent, SQLite schema, or scheduling algorithm implementation.

## Requirements

- Node.js `>= 22.19.0`
- pnpm `11.7.0`

Use Corepack to run the pnpm version declared by the repository:

```bash
corepack enable
pnpm install
```

## Local development

```bash
pnpm dev
```

The development server runs at `http://localhost:3000` by default.

## Common commands

| Command                | Purpose                                                        |
| ---------------------- | -------------------------------------------------------------- |
| `pnpm dev`             | Start the development server                                   |
| `pnpm generate-routes` | Regenerate the TanStack Router route tree                      |
| `pnpm check`           | Check formatting with Prettier                                 |
| `pnpm lint`            | Run ESLint                                                     |
| `pnpm typecheck`       | Run TypeScript type checking                                   |
| `pnpm test`            | Run Vitest; currently allows no test files                     |
| `pnpm build`           | Build for production                                           |
| `pnpm verify`          | Run formatting, lint, type, test, and build checks in sequence |

## Main directories

```text
src/routes/                 TanStack Router file routes
src/lib/                    Shared utilities; currently only shadcn's cn utility
src/routeTree.gen.ts         Generated route tree; do not edit manually
components.json             shadcn/ui and FullCalendar registry configuration
docs/                       Current architecture and long-term engineering principles
.agents/                    Repository-local skills, decisions, postmortems, and execution plans
AGENTS.md                   Minimal entry point for coding agents
```

## UI and FullCalendar

`components.json` registers the official FullCalendar shadcn registry, but no calendar components have been generated yet. When UI implementation begins, choose a FullCalendar flavor, for example:

```bash
pnpm dlx shadcn@latest add @fullcalendar/monarch-event-calendar
```

Review the components the registry will generate, then retain the parts needed for the project's layout.

## Database and agent

SQLite, Drizzle, and pi Agent SDK are currently installed only as dependencies:

- No `drizzle.config.ts`, database files, or migrations have been created.
- No model provider or API key has been configured.
- No agent session, tool, or system prompt has been created.
- No mapping from FullCalendar `EventInput` to SQLite has been defined.

Keep all secrets in uncommitted local environment variable files, never in source code or this README.

## Agent Harness

The repository uses `minimal-agent-harness` to generate a minimal local harness. Coding agents should read [AGENTS.md](AGENTS.md) first and load only the documentation, skills, or active plans relevant to the current change.
