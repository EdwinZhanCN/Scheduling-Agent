# Agent Guide

This is the minimal entry point for coding agents working in the Scheduling Agent repository. See [README.md](README.md) for installation instructions and command reference.

## Product invariants

- SQLite is the ultimate source of schedule facts. The UI receives them through domain structures close to FullCalendar `EventInput`; FullCalendar runtime objects are not the persistence source.
- The agent may only read schedules and generate change proposals. Creating, moving, or deleting events requires explicit approval before changes can be committed.
- Hard constraints and conflict detection belong to deterministic scheduling code, not free-form model generation.
- The repository currently provides only dependencies and tooling scaffolding; do not describe placeholder pages as implemented product capabilities.
- **i18n follows the Extract then Fill rule**: extract all user-facing UI text into `src/i18n/locales/en.json` first, then reference it in components through `useTranslation()` / `t(...)`. Only English is currently supported.

## Repository map

- `src/routes/`: TanStack Start file routes and application entry points.
- `src/lib/`: Shared application utilities, including shadcn's `cn` utility and demo data.
- `src/i18n/`: i18next initialization and translation resources in `locales/en.json`.
- `src/styles.css`: Global styles for Tailwind and shadcn.
- `components.json`: shadcn aliases and FullCalendar registry configuration.
- `docs/`: Current architecture and long-term engineering principles.
- `.agents/`: Reusable procedures, decisions, postmortems, and unfinished execution plans.

## Read before changing

- Read [`docs/architecture.md`](docs/architecture.md) before changing runtime boundaries, data ownership, or module organization.
- Read [`docs/core-beliefs.md`](docs/core-beliefs.md) when making product scope or engineering tradeoffs.
- Check `.agents/exec-plans/active/` and read only active plans relevant to the current change.

## Recurring procedures

- [`scheduling-agent-select-checks`](.agents/skills/scheduling-agent-select-checks/SKILL.md): Select the narrowest reliable verification commands based on the actual diff.

## Non-negotiable boundaries

- `src/routeTree.gen.ts` is generated by `pnpm generate-routes`; never edit it manually.
- Modify dependencies through pnpm or an official scaffolding CLI; never manually edit dependency entries in `package.json` or the lockfile.
- `better-sqlite3`, Drizzle data access, and the pi Agent runtime belong exclusively in server modules and must not be imported directly by browser components.
- Extract user-facing text into `src/i18n/locales/en.json` following the **Extract then Fill** rule; never hardcode it in JSX or components.
- Select checks using the local skill before claiming completion; run `pnpm verify` by default for changes across layers or to dependencies.

## Durable memory

- `.agents/decisions/` holds only project-level rationale that future work may revisit.
- `.agents/postmortems/` holds only systemic failures that escaped the development loop and must link to real guardrails.
- `.agents/exec-plans/active/` holds only unfinished, multi-phase work; extract durable conclusions and delete the plan when complete.
